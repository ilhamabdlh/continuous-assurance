Fitur kita vs kompetitor + Rapid7

Rapid7 punya dua lini yang paling relevan: Exposure Command (platform CTEM / assessment) dan Vector Command (jasa continuous red team + validasi manusia). Vector Command adalah analog terdekat dengan arah Continuous Assurance Atumcell.

Platform

Exposure Command

CTEM / Exposure Assessment Platform. Menggabungkan InsightVM + Surface Command (ASM) + cloud + app risk. Fokus: inventaris hybrid, skor berbasis ancaman, attack path, otomasi remediasi. Leader Gartner EAP 2025.

Paling mirip kita

Vector Command

Managed continuous red team: recon eksternal berkelanjutan + operator manusia yang mengeksploitasi eksposur secara aman. Same-day report, emergent threat validation, vetted attack paths. Advanced + pentest internal tahunan.

Fondasi

Surface + InsightVM

Surface Command = attack surface / CAASM. InsightVM = scanner VM klasik, kini jadi mesin di dalam Exposure Command. Bukan “assurance manusia”, melainkan assessment otomatis + kontekstual.

Knowledge dari Rapid7 yang patut diambil

  • Pisahkan platform vs jasa manusia. Exposure Command = tool assessment. Vector Command = manusia yang memvalidasi. CA Atumcell paling dekat ke Vector, bukan meniru Exposure Ultimate.
  • Loop Discover → Exploit → Prioritize → Remediate. Buat siklus ini terlihat di UI (kita sudah punya potongan; bisa diperjelas di Ringkasan).
  • Same-day reporting untuk exploit sukses. Jangan biarkan temuan kritis menunggu “batch mingguan” tanpa SLA yang jelas.
  • Emergent threat validation. Saat KEV / CVE panas muncul, ada jalur cepat “validasi sekarang” — bukan hanya badge.
  • Attack path / asset attractiveness. Prioritas bukan hanya CVSS, tapi “apakah bisa dirantai ke aset berharga”. Cocok untuk backlog v2.
  • Coverage gaps. Tampilkan aset yang ditemukan tapi belum masuk cakupan uji — Rapid7 menekankan ini; kita sudah mulai dengan “belum diperiksa”.
  • Advanced = continuous + pentest berkala. Model Vector Command Advanced (red team kontinu + internal tahunan) sangat mirip paket “Continuous Assurance + siklus pengujian” kita.

Di mana kita beda / jangan ikut

  • Jangan kejar CNAPP + 500 konektor. Itu medan Exposure Command Ultimate / Wiz / CrowdStrike. Atumcell menang di agentless eksternal + manusia.
  • Sertifikat penutupan bertanggal belum terlihat sebagai artefak produk di Rapid7 — ini tetap pembeda kita untuk asuransi & auditor.
  • Label validasi di UI per temuan lebih eksplisit daripada laporan red team yang “tersembunyi” di PDF.
  • Portofolio PE + pricing mid-market bukan fokus Rapid7; Bitsight lebih dekat di sini, tapi tanpa validasi manusia Atumcell.
  • Bahasa positioning: Rapid7 jual “command your attack surface”. Kita bisa jual “assurance yang bisa dibuktikan” — keyakinan, bukan hanya inventaris.
