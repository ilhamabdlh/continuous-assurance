## Run the prototype

```bash
cd ca-app
npm install
npm run dev
```

Open http://127.0.0.1:5173

## Positioning (short)

Not full compliance automation (Vanta) and not ratings-only (Bitsight). Closest market analog: Rapid7 Vector Command — with differentiators around human-validated labels, dated closure certificates, testing cycle, PE portfolio, and insurance binder.
